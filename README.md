# AWS Production-Ready Full-Stack Deployment

## Project Overview

A production-style full-stack application deployed on AWS, focusing on cloud architecture, security, reliability, cost optimization, automation, monitoring, and Infrastructure as Code (IaC).

## Tech Stack

- **Frontend:** React
- **Backend:** Node.js / Express REST API
- **Database:** PostgreSQL

## AWS Architecture Highlights

- **Networking & Security:** Custom VPC, Public/Private Subnets, Least-Privilege Security Groups
- **Compute & Scaling:** EC2 Auto Scaling, Application Load Balancer (ALB)
- **Storage & Database:** RDS PostgreSQL (Single-AZ Free Tier), S3
- **Management & Monitoring:** CloudWatch Metrics/Alarms, SSM Parameter Store
- **DevOps & IaC:** Terraform, GitHub Actions with OIDC Authentication
